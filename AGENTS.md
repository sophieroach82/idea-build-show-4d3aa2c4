# Project rules
- Keep product metadata in a shared typed catalog so homepage browsing and individual case studies stay consistent.
- Present process books within product case studies using pre-rendered page assets, not PDF embeds; this keeps chapters readable on all devices.
- Keep professional experience and education details in a shared typed resume module, with the uploaded document asset as the download source, so previews and dedicated pages stay consistent.
- Resolve CDN pointer URLs through the shared asset URL helper and download documents as blobs so media and downloads work on local and external hosting as well as Lovable.
